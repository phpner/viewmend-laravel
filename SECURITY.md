# Security Policy

## Supported versions

Security fixes are provided for the latest stable `1.x` release. Pre-release and unsupported versions should be upgraded before reporting a compatibility issue.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email [support@viewmend.com](mailto:support@viewmend.com) with:

- the affected package and version;
- a clear description and reproduction steps;
- the expected impact;
- any suggested mitigation, if known.

Please avoid including active API tokens, authorization headers, customer data, or raw production responses. Use redacted examples and revoke any credential that may have been exposed.

We will acknowledge the report, investigate it, and coordinate remediation and disclosure with the reporter. Public disclosure should wait until a fix or mitigation is available.
